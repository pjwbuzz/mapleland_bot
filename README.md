# 메이플랜드 길드 가입봇 — Windows 실행 안내

## 이번 업데이트 적용 방법 (이미 실행 중인 경우)

1. 실행 창에서 Ctrl+C를 눌러 봇을 종료하세요.
2. 기존 `applications.db`를 복사해 백업하세요.
3. 업데이트 ZIP을 압축 해제하고 새 `bot.py`만 기존 실행 폴더에 덮어쓰세요. README와 test_bot.py는 필요하면 함께 교체하세요.
4. 기존 `config.json`, `applications.db`, `.venv`는 유지하세요. 토큰 재입력이나 재설치는 필요 없습니다.
5. `start.bat`를 실행하세요. 기존 DB에 선택정보 저장 칸이 자동 추가되며 신청 이력은 유지됩니다.
6. Discord에서 `/가입설치`를 다시 실행하고 기존 #가입신청 채널을 선택하세요. 기존 안내 메시지에 개인정보 안내가 반영됩니다.

### 신청 화면 변경

- 첫 화면: 닉네임/직업/레벨 및 가입 경로 / 초대한 사람(필수), 추가 내용(선택).
- 가입 경로 / 초대한 사람 질문: "길드 가입하게 된 경로가 어떻게 되시나요? 길드 초대한 사람 누군지 적어주세용." 초대한 사람이 없다면 "검색 / 없음"처럼 작성하면 됩니다. 공백만 작성할 수 없고 최대 400자입니다.
- 가입 경로 답변은 가입심사 채널과 DB에 저장됩니다. 별명 형식에는 포함되지 않습니다. 이전 신청 이력은 그대로 유지되고 기존 신청서는 해당 항목이 "기존 신청서: 미수집"으로 표시됩니다.
- 기본정보 입력 후 본인에게만 보이는 개인정보 안내가 나옵니다.
- `선택정보 작성 후 제출`: 나이/성별/거주지역을 각각 입력합니다. 모두 선택 항목이며 일부 또는 전부 비워도 제출됩니다.
- `건너뛰고 신청서 제출`: 개인정보를 전혀 작성하지 않고 제출합니다.
- 선택 화면을 완료하지 않고 닫았다면 아직 신청되지 않은 상태입니다. 10분 안에 위 버튼 중 하나로 완료하거나 처음부터 다시 신청하세요. 제출 전 화면은 봇 재시작 후 복원되지 않습니다.
- 나이는 `29`, `20대` 등 편한 표현으로 입력할 수 있습니다. 거주지역은 시·도 정도만 입력하며 상세 주소는 적지 않도록 안내합니다.
- 서버 별명은 계속 `닉네임 | 직업 | Lv.레벨`이며 나이/성별/지역은 포함되지 않습니다.

안내 문구:

> 나이·성별·거주지역은 모두 선택 항목입니다. 불편한 항목은 비워두거나 전체를 건너뛰어도 가입 신청이 가능합니다. 작성한 개인정보는 길드 관리 목적으로 관리자만 확인하며, 일반 길드원에게 공개하지 않습니다. 거주지역은 시·도 정도만 적어주세요. 상세 주소는 적지 마세요.

선택정보는 비공개 #가입심사 메시지와 운영 PC의 applications.db에 저장됩니다.
일반 채널/별명/가입안내 DM/가입 로그에 선택정보를 싣지 않습니다. 관리자와 DB를 보관하는 운영자는 확인할 수 있습니다.
가입심사 채널이 일반 역할이나 멤버에게 보이면 봇 시작 또는 신청 제출을 차단합니다.
Discord Administrator 권한이 있거나 config.json의 admin_role과 같은 이름의 역할을 가진 사람이 관리자입니다.
이 역할을 일반 길드원에게 주지 말고, 운영진도 심사 메시지를 공개 채널로 옮기거나 공유하지 마세요.
운영 PC의 DB·백업 파일도 운영진만 접근할 수 있도록 보관하세요.

검증: 로컬 모의 테스트 15개 통과. 가입 경로 필수 입력·저장, 선택정보 미작성/일부 작성/전체 작성, 비공개 채널 검사, 기존 DB 자동 업데이트를 포함합니다.
실제 Discord 서버에서도 업데이트 후 선택정보 작성과 건너뛰기 두 경로를 각각 테스트하세요.

Discord에 봇을 넣고 역할 순서를 정한 다음 진행하는 단계입니다.
Python/discord.py/SQLite로 실행하며 유료 서비스와 AI API를 사용하지 않습니다.
PC가 켜져 있고 프로그램이 실행 중일 때 작동합니다. 오프라인 동안 신청/승인 버튼은 응답하지 않습니다.

## 1. 채널과 권한 준비

`#가입신청`과 `#가입심사` 텍스트 채널을 준비하세요. 두 채널은 반드시 구분합니다.
선택 사항으로 `#가입로그`도 만들 수 있습니다.

| 위치 | @everyone | 가입대기 | 길드원/용병 | 관리자 | 봇 |
|---|---|---|---|---|---|
| 가입신청 | 보기·기록 읽기 허용, 메시지 보내기 차단 | 역할로 추가 허용 불필요 | 보기 허용 | 보기 허용 | 보기·보내기·링크 첨부·기록 읽기 허용 |
| 가입심사/가입로그 | 보기 차단 | 별도 허용 없음 | 별도 허용 없음 | 보기 허용 | 보기·보내기·링크 첨부·기록 읽기 허용 |
| 길드 전용 채널 | 보기 차단 | 별도 허용 없음 | 길드원에게만 보기 허용 | 보기 허용 | 필요한 채널만 허용 |
| 용병 전용 채널 | 보기 차단 | 별도 허용 없음 | 용병에게만 보기 허용 | 보기 허용 | 필요한 채널만 허용 |

중요: 신규 멤버는 봇이 역할을 주기 전에도 가입신청 채널을 볼 수 있어야 합니다.
가입대기 역할에만 가입신청 채널 보기를 허용하지 마세요.
기존 다른 역할이나 카테고리의 권한이 비공개 채널 보기를 허용하지 않는지도 확인하세요.
봇은 채널 권한을 자동으로 바꾸지 않습니다.

서버 기본 참가신청 기능은 봇 신청과 겹치므로 끄세요. 규칙 동의 화면이 남아 있다면 먼저 동의해야 신청 버튼을 사용할 수 있습니다.

봇 역할은 길드원·용병·가입대기보다 위에 놓고 역할 관리/별명 관리 권한을 주세요.
Developer Portal → Bot → SERVER MEMBERS INTENT를 켭니다.
봇 설치 Scope에는 bot 및 applications.commands가 포함되어야 합니다.
관리자는 서버의 Administrator 권한이 있거나 설정에 지정한 `관리자` 역할을 가진 사람입니다.
이 역할을 가진 사람은 승인/거절/용병전환이 가능하므로 운영진에게만 주세요.

## 2. Python 설치

[Python Windows 다운로드](https://www.python.org/downloads/windows/)에서 Python 3.10 이상을 설치하세요.
Python 설치 프로그램을 사용한다면 Add Python to PATH 옵션을 체크하세요.
명령 프롬프트에서 `py -3 --version`이 작동해야 합니다.

## 3. 설치 파일 실행

ZIP을 **압축 해제**하고 `guild-bot` 폴더의 `install.bat`를 더블클릭하세요.
인터넷 연결이 필요하며 최초에 가상환경과 discord.py를 설치합니다.
설치가 끝나면 `config.json`이 생깁니다.
압축 파일 안에서 바로 실행하지 마세요.

## 4. 설정 입력

Discord → 사용자 설정 → 고급 → 개발자 모드를 켭니다.

- 서버 아이콘 우클릭 → 서버 ID 복사
- #가입심사 우클릭 → 채널 ID 복사
- 선택: #가입로그 우클릭 → 채널 ID 복사

Developer Portal → 해당 앱 → Bot → Reset Token에서 토큰을 발급·복사합니다.
메모장으로 `config.json`을 열어 세 항목을 바꾸세요.

```json
"token": "복사한 토큰",
"guild_id": "복사한 서버 ID",
"review_channel_id": "복사한 가입심사 채널 ID"
```

따옴표와 쉼표는 그대로 두고 안쪽 내용만 바꿉니다. ID는 채널 이름이 아닌 긴 숫자입니다.
가입로그가 없다면 `log_channel_id`는 빈 문자열로 유지하세요.
길드원·용병·가입대기·관리자 역할 이름이 실제 서버와 다르면 설정의 역할 이름도 수정하세요.
역할 이름에 이모지나 공백이 있다면 그대로 일치시켜야 합니다. 관리 대상 세 역할 이름은 각각 하나만 있어야 합니다.
`welcome_message`를 바꾸면 승인 DM 안내문을 바꿀 수 있습니다.

토큰은 비밀번호입니다. 채팅에 보내거나 GitHub에 올리지 마세요.
노출됐다면 Reset Token 후 설정의 토큰도 교체하세요.

## 5. 봇 켜기와 신청 버튼 설치

`start.bat`를 더블클릭하세요. `봇 온라인` 안내가 뜨면 성공입니다.
봇이 오프라인이었던 것은 실행 프로그램이 아직 없었기 때문일 수 있습니다.

Discord 서버에서 운영진 계정으로 아래 명령을 입력하고 채널 선택 칸에서 #가입신청을 선택하세요.

```text
/가입설치 channel:#가입신청
```

설치가 끝나면 신청 버튼이 생깁니다. 같은 채널에서 명령을 다시 실행하면 저장된 안내 메시지를 갱신합니다.
명령이 안 보이면 Discord를 새로고침하고 설치 Scope에 applications.commands가 있는지 확인하세요.

## 6. 실제 테스트

서버장이나 봇보다 높은 역할의 계정은 별명 변경이 제한됩니다. 일반 테스트 계정을 사용하세요.

1. 일반 링크로 입장 → 가입대기 역할 및 가입신청 채널 표시 확인.
2. 신청 버튼 클릭 → 닉네임·직업·레벨 입력 → 관리자 채널에서 신청서 확인.
3. 승인 클릭 → 길드원 지급, 용병/가입대기 제거, 별명 변경, DM 확인.
4. 중복 승인 클릭 → 이미 처리됨 확인. 다른 계정의 거절도 테스트.
5. DM 수신을 막은 계정 승인 → 가입은 성공하고 심사 메시지에 DM 실패 표시 확인.
6. 심사 중 봇을 종료·재시작 → 기존 심사 버튼이 계속 작동하는지 확인.
7. 관리자가 길드원+용병을 동시에 부여 → 봇이 용병을 제거하는지 확인.
8. 용병 전용 초대링크 입장 → 용병만 유지되고 가입대기가 제거되는지 확인.

서버 별명 예시: `정우전사 | 나이트로드 | Lv.87`.
전체 32자를 넘는 신청은 입력 단계에서 안내합니다. 레벨은 1~200만 받습니다.
거절은 서버 추방을 의미하지 않습니다. 신청자는 가입대기/기존 용병 상태를 유지하며 다시 신청할 수 있습니다.

## 7. 용병 초대링크

Discord 공식 안내: 서버 이름 → 서버에 초대 → 초대 링크 편집 → Roles (Optional)에서 용병 선택 → 새 링크 생성.
일반 링크에는 역할을 지정하지 않습니다. 이 봇은 링크 사용량으로 가입 경로를 추측하지 않습니다.
해당 역할 선택 항목이 본인 UI에 안 보이면 운영진이 아래 명령으로 전환할 수 있습니다.

```text
/용병전환 member:@사용자
```

이 명령은 운영진의 명시적 전환이므로 기존 길드원 역할도 제거합니다.
길드원이 용병 링크를 눌러 두 역할이 생기는 경우에는 길드원을 유지하고 용병을 제거합니다.
Discord 역할 포함 초대 안내: https://docs.discord.com/developers/communities/guides/community-invites

## 운영과 보관

- 봇은 **한 번에 하나만** 실행하세요. 실행 창을 닫거나 Ctrl+C를 누르면 종료됩니다.
- 창을 최소화해도 실행됩니다. PC 종료·절전 시 사용할 수 없습니다.
- 봇 재시작 시 역할 중복을 점검합니다. 길드원/용병이 없는 기존 일반 멤버에도 가입대기를 부여합니다.
- 봇이 역할 변경을 처리할 때 잠깐 중복 상태가 있을 수 있습니다. Discord 자체가 두 역할 동시 부여를 금지하는 것은 아닙니다.
- 승인 중 별명/역할 API 호출이 실패하면 일부 변경이 적용될 수 있습니다. 심사 상태는 유지되며 권한 수정 후 승인 재시도가 가능합니다.
- 안내문 업데이트나 DM 실패는 확정된 승인을 취소하지 않습니다. 확정 후 강제 종료되면 DM은 자동 재전송하지 않습니다.
- 심사 메시지를 수동 삭제하면 해당 신청은 DB에 남습니다. 운영 중 심사 메시지/DB를 임의로 삭제하지 마세요.
- 데이터는 `applications.db`, 실행 기록은 `bot.log`에 저장됩니다. 이름·신청 내용이 있으므로 운영진만 보관하세요.
- GitHub에는 bot.py/requirements.txt/안내문/설정 예시만 올리세요. `.gitignore`가 실제 설정·DB·로그를 제외합니다.
- 무료 서버 이전 시 소스와 DB를 복사하고 토큰은 서버에 따로 설정하면 됩니다. 이번 버전에는 클라우드 배포가 포함되어 있지 않습니다.

개발 검증은 Python 구문과 로컬 모의 테스트로 진행했습니다. 토큰과 실제 서버 설정을 사용한 Discord 통합 테스트는 위 순서로 진행해야 합니다.
버튼 유지 구현 참고: https://discordpy.readthedocs.io/en/stable/interactions/api.html#discord.ui.View.is_persistent
